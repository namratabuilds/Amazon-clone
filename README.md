# Amazon Homepage Clone

A static front-end recreation of the Amazon homepage built using **HTML5 and CSS3**. This beginner-friendly project focuses on developing practical web design skills by recreating a familiar e-commerce interface.

> **Note:** This is an educational project. It is not affiliated with Amazon and does not support real shopping, payments, or user authentication.

## Preview
The screenshots are attached in the Images files

## Features

- **Navigation Bar:** Logo, delivery location, search bar, account section, and cart layout.
- **Category Navigation:** Secondary navigation bar with category links.
- **Hero Section:** Large promotional banner.
- **Product Sections:** Grid-based product and category cards.
- **Footer:** Organized link sections and a back-to-top bar.
- **Interactive Styling:** Hover effects and CSS transitions.
- **Structured Layout:** Flexbox and CSS Grid for element alignment and product layouts.

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic elements |
| CSS3 | Styling, colors, spacing, and visual effects |
| Flexbox | Navigation and component alignment |
| CSS Grid | Product and category layouts |

**Dependencies:** None. Built using plain HTML and CSS, without JavaScript, frameworks, or external libraries.

## Key Learnings

Through this project, I gained practical experience in:

- Structuring webpages using semantic HTML elements.
- Building navigation layouts with CSS Flexbox.
- Creating product grids using CSS Grid.
- Applying spacing, typography, colors, and borders.
- Implementing hover effects and transitions.
- Organizing HTML, CSS, and image assets into a maintainable project structure.
- Translating a real-world website layout into a front-end implementation.
